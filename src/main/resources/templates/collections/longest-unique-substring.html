Longest Substring Without Repeating Characters

Find the length of the longest contiguous part of the input string in which no Java char occurs more than once.

What is a substring?

A substring is a continuous part of the original string.

"bcd" is a substring of "abcde". "ace" is not a substring because its characters are not next to each other.

Method

public static int longestUniqueLength(String text)

Rules

  • Return 0 for null.
  • Return 0 for an empty string.
  • Spaces, punctuation and digits count as characters.
  • Uppercase and lowercase letters are different.
  • Do not generate every possible substring.
  • Do not restart the search from every character.
  • Aim for average O(n) execution time.
  • Prefer HashMap<Character, Integer>.

Example 1

Input: "abcabcbb" Output: 3 Explanation: "abc" is the longest substring without repeated characters.

Example 2

Input: "bbbbb" Output: 1

Example 3

Input: "pwwkew" Output: 3 Explanation: "wke" is a valid answer.

Important edge case

Input: "abba" Output: 2 The left side of the current window must never move backwards.

Hints

  1. Keep a left and right boundary for the current valid window.
  2. Move the right boundary through the string once.
  3. Store the most recent index of every character.
  4. When a repeated character is inside the current window, move the left boundary past its previous position.

Expected complexity

Average time: O(n)

Additional memory: O(k)
